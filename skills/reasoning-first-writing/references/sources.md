# Research and influences

These are design influences, not runtime dependencies or sources for claims in a user's draft. Reviewed on 2026-11-02. Local templates and active method contracts still govern the artifact.

| Source | Applied principle | Boundary |
| --- | --- | --- |
| [Google developer style: tone](https://developers.google.com/style/tone) | Conversational, direct, respectful technical prose | Natural language does not require invented personality or forced informality |
| [Google technical writing: words](https://developers.google.com/tech-writing/one/words) | Consistent terminology and audience-appropriate definitions | Preserve precise terms rather than removing all jargon |
| [Google technical writing: sentences](https://developers.google.com/tech-writing/one/short-sentences) | Direct verbs and understandable sentence structure | No shared numeric sentence limit across artifact types |
| [Google developer style: tables](https://developers.google.com/style/tables) | Tables for comparable structured information | No universal table or table-cell sentence rule |
| [Diataxis: explanation](https://diataxis.fr/explanation/) | Explain context and the reasons behind a subject | Explanation does not replace procedural or reference artifacts |
| [Google technical writing: illustrations](https://developers.google.com/tech-writing/two/illustrations) | Use visuals to explain information that benefits from visual representation | No fixed diagram quota |
| [W3C: planning accessible audio and video](https://www.w3.org/WAI/media/av/planning/) | Plan spoken information with the visual content and audience needs | Writing a script does not prove accessibility or successful production |
| [Agent Skills specification](https://agentskills.io/specification) | Discoverable skill entry points and selectively loaded references | No portable dependency resolver is declared by the specification |

Promptlings separates shared expression from spoken delivery and artifact-specific writing. The fidelity rules are explicit safeguards: style changes cannot establish evidence, approve a decision, invent ownership, or discard a required distinction.
